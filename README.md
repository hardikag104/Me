# 🎯 Me — Personal Life Operating System (PWA)

A minimalist, high-performance, dark-themed Progressive Web App built to bring discipline, order, and consistency to daily student life.

## 🚀 Features

- 🏫 **Timetable & Attendance**: Complete BITS Pilani class schedule with real-time class pulse, attendance tracker with 75% safety guard, safe-to-bunk & must-attend recovery calculator, and per-class note taking.
- 📝 **Tasks & Chores**: Categorized to-do list (Daily chores, Tests/Exams, Meetings, Urgent) with countdown badges, dynamic custom recurring habits (Hair oiling, Dry fruits, Hydration), and a "Somebody Told Me" quick capture scratchpad.
- 🍎 **Food & Health Intelligence**: Meal logging with instant food quality analysis, junk food detection, nutritional advice, daily health score (0-100%), and an 8-glass / 3L interactive hydration tracker.
- 😴 **Sleep & Discipline**: 11:00 PM bedtime cutoff, 6:30 AM wake-up target, sleep consistency scoring, late-night reality check lockdown overlay (11 PM - 5 AM), and a hard-hitting emotional motivation engine (Parents' sacrifices, Career competition, Future self, BITSian toughness).
- 💾 **100% Offline & Private**: Works completely offline via Service Worker. 1-click JSON backup & restore for seamless transfer between PC and Android.
- 📲 **Installable PWA**: Tap "Add to Home screen" on Android Chrome or install via desktop browser.

## 🛠️ How to Run Locally

Open `index.html` directly in Google Chrome or any modern browser:
```
file:///D:/Me/life-tracker/index.html
```

## 🌐 GitHub Pages Deployment

1. Repository: `https://github.com/hardikag104/Me`
2. Go to **Settings** > **Pages**
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**
4. Your PWA will be live at `https://hardikag104.github.io/Me/`
